# The Top English — Protótipo Inicial

Protótipo institucional em HTML + CSS + JavaScript, baseado na identidade visual observada na planilha fornecida pela equipe.

## Estrutura
- index.html — página principal
- style.css — identidade visual e responsividade
- script.js — menu mobile, formulário demonstrativo e botão voltar ao topo
- assets/identidade-top-english.png — recorte da identidade visual da planilha

## Como executar
Abra o arquivo `index.html` em um navegador.

## O que o protótipo demonstra
- Apresentação institucional da escola
- Metodologia e modalidades
- Página/seção de captação de interessados
- Formulário de pré-atendimento
- Canais de contato
- Fluxo conceitual Google → Site → Contato
- Layout responsivo

Observação: o formulário é demonstrativo. Ele não envia dados para um banco ou WhatsApp real.
